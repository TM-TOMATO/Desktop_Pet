# 🎨 Desktop Pet 스프라이트 에셋 제작 및 가이드

사용자님이 제작하신 이미지를 `assets/sprites/` 폴더 내에 아래 지정된 파일명으로 넣어주시면, 게임 실행 시 자동으로 해당 에셋을 로드하여 펫 애니메이션으로 사용합니다!

*(이미지가 아직 폴더에 없는 경우, 개발용 귀여운 젤리/슬라임 형태의 Placeholder 그래픽이 대신 렌더링됩니다.)*

---

---

## 2. 에셋 제작 팁
- **포맷**: 배경이 투명한 **32-bit PNG** (또는 `.webp`)
- **기준점 (Anchor/Pivot)**: 캐릭터의 발바닥(하단 중앙)이 바닥 기준점이 됩니다.
- **애니메이션 프레임시트 지원 (추후 확장)**:
  - 여러 프레임의 가로 스프라이트시트를 사용할 경우, `pet_walk_sheet.png` 형태로 프레임 분할 정보를 지정할 수 있습니다.
