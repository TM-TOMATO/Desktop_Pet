# 📌 Desktop Pet 개발 규칙 & 중요 부탁 메모

> 이 파일은 자주 언급되는 중요한 요청과 규칙을 기록합니다.
> 개발 시 항상 이 파일을 참고해주세요.

---

## ⚙️ 시스템/개발 규칙

- **Git 자동 커밋**: 작업 완료 시 반드시 `git add . && git commit -m "..." && git push origin main` 실행
- **창 위치**: 앱 실행 시 기본값은 **항상 위에 고정**, 화면 **정중앙**에 띄우기
- **에셋 새로고침**: 개발자 모드에서 에셋 새로고침 버튼으로 앱 재시작 없이 스프라이트 즉시 반영
- **중요 요청은 이 파일에 기록**: 자주 반복되거나 설계 의도가 담긴 요청은 이 파일에 추가

---

## 🎮 스프라이트 & 에셋 규칙

- **스프라이트는 사용자가 직접 제작**, 파일명은 개발자가 지정 후 사용자가 그 이름으로 저장
- **제작할 스프라이트 목록은 `docs/sprite-checklist.md`에 최신 상태 유지**
- **폴더별 분할 관리**: `assets/sprites/` 하위에 카테고리별 폴더(`pet`, `console`, `menu_main`, `menu_feed`, `menu_play`, `menu_shop`, `menu_status`, `menu_config`, `menu_dev`)로 정리하여 파일 관리
- **모든 스프라이트는 256x256 PNG** (레이어 오버레이 방식, 투명 배경)
- **크기 조절 스프라이트**: 100%~300% (10% 단위) 수치별로 Normal / Active 분할 제작 지원 (`config_scale_*.png`)
- **항상 위에 고정 스프라이트**: 4종(비선택_꺼짐 `config_top_off`, 선택_꺼짐 `config_top_off_active`, 비선택_켜짐 `config_top_on`, 선택_켜짐 `config_top_on_active`) 분할 제작 지원
- **폰트**: Galmuri9 (`pixel_font.ttf`) — 반드시 **9px 정수 크기**로만 렌더링해야 도트 깨짐 없음 (`-webkit-font-smoothing: none`)
- **메뉴 라벨 커서**: 별도 커서 아이콘 없음 — Active 스프라이트 자체에 선택 표시 포함
- **창 배경**: 메인 메뉴, 먹이, 상점, 스텟, 설정 등 모든 팝업창 배경은 `ui_modal_bg.png`를 공통으로 재활용
- **낙하 음식**: 별도 낙하 스프라이트 없이 `item_*.png` 아이콘 그대로 재사용

---

## 🐾 펫 이동 & 애니메이션 규칙

- **Walk 모션**: 땅에 닿아있는 프레임(`isGroundedFrame = true`)에서는 수평 이동 **멈춤**, 공중 프레임에서만 이동
- **펫 스케일**: 1:1 정수 스케일(`1.0`)로 렌더링해야 도트 뭉개짐 없음 — 소수점 스케일 금지
- **8방향 십자키 통합**: 십자키는 단일 스프라이트로 통합, 눌림은 8방향 개별 스프라이트로 구분

---

## 📋 UI & 메뉴 규칙

- **클릭수 표시**: 메인 화면 상단 HUD(`counter_bg.png` 위)에 항상 표시
- **메뉴 복귀 시 커서 유지**: 서브메뉴에서 [B] 뒤로 가기 시, 이전에 선택했던 메인 메뉴 항목이 그대로 선택 상태 유지
- **꾹 누름 코인 버그**: 마우스 버튼을 길게 눌러도 코인이 연속 증가하지 않도록 디바운스 처리
- **전원 버튼 10초**: 10초 이상 누르면 개발자 모드 토글 (10초 미만 누르기는 정상 종료)
- **메뉴 닫기 시**: 모든 256x256 오버레이 레이어(title, label, modal)도 완전히 `hidden` 처리

---

## 🛒 상점 & 먹이 규칙

- **상점 아이템 행**: 메인 메뉴 라벨처럼 선택(Active) / 비선택(Normal) 256x256 레이어 2장으로 구분
- **크기 조절**: 마우스 조작은 불가하며, 레트로 도트 게이지 바로 표시됨. CONFIG 메뉴에서 크기 항목 선택 후 **[◀/▶] 방향키 및 십자키 버튼**으로만 100%~300% 조절 가능

---

## 🔧 설정 & 개발자 모드

- **토글 스위치 조작**: 설정 및 개발자 창의 토글 스위치 항목은 선택 후 **[◀] 방향키로 OFF**, **[▶] 방향키로 ON** 전환 (A 키로도 토글 가능)
- **작은 화면 모드**: 설정창 대신 본체 우측 상단의 `[🗗]` 전용 버튼으로 바로 전환 (미니 창에서 `⤢` 클릭 시 복귀)
- **개발자 모드 창**: 설정(CONFIG) 메뉴 내 `🛠️ 개발자 모드 >` 선택 시 전용 서브 모달 진입
- **개발자 도구 항목**: 플레이어의 게임 경험을 해치는 치트(골드/스텟 등)는 배제하고, **히트박스 표시** 및 **에셋 새로고침** 등 순수 개발 도구만 제공
- **전원 버튼 10초**: 10초 이상 꾹 누르면 개발자 모드 토글 가능 (10초 미만은 정상 종료)
